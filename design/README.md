# Design originals

Full-size source images, kept for print and editing. They are **not** served by the website (anything in `public/` is publicly downloadable and counts toward every deployment); the site uses the smaller WebP copies in `public/assets/`.

- `Ghmo-building.png`: 3500 × 2333 artwork of the planned Gumba building (site copy: `public/assets/ghmo-building.webp`).
- `ghmo-letterhead.png`, `ghmo-seal.png`: document generator artwork (site copies: `public/assets/docgen/*.webp`).
